# Micrograd

Lesson #1: Backpropagation, the essence of neural networks, and how to write a minimal autograd engine

`main.py` contains the Value class and `torchimpl.py` contains a similar implementation of scalar backprop using PyTorch API following Karpathy's example
for now everything (Value class, nn engine, & a short neural net demo) lives in `main.py` at around 200 lines that im keeping this way since its honestly quite an elegant look into what's really going on in a neural net (and just how simple everything is)
